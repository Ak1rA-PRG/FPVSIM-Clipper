# FPVSIM-Clipper

> **配布準備中**：Windows版の動画書き出し検証と、同梱ライブラリの再配布条件を確認しています。現在、正式リリースはありません。


VelociDroneの自己ベスト更新を検出し、OBS Studioのリプレイバッファから飛行動画を保存する非公式ツールです。


## 主な機能


- 1周・3周の自己ベストを検出し、記録タイムに合わせてクリップを保存
- コース名・機体名の自動取得
- ファイル名・保存フォルダの命名ルールをカスタマイズ
- Xへの投稿文を自動作成


## 導入手順


事前にOBS Studioをインストールしてください


配布準備が整い次第、[GitHub Releases](https://github.com/Ak1rA-PRG/FPVSIM-Clipper/releases)でWindows版の公開を予定しています。
公開後は、ZIPファイルをダウンロードし、任意のフォルダに展開してください。
解凍後に`FPVSIM-Clipper.exe`を開いてください
自動でセットアップウィザードが開くのでウィザードに従って設定してください


## 注意点


通信状況などによりタイムを自動取得できない場合があります。


3周タイムを取得できなかった場合は、元動画の保存後にタイム入力を案内します。OBSや通信の状態によっては元動画も保存できない場合があります。


## 対応環境


- Windows 10 / 11（64ビット）：配布版はPythonのインストール不要
- OBS Studio：録画・リプレイバッファに必要
- VelociDrone：接続にはゲーム側でWebSocket通信を有効にする必要があります


## 保存とタイムの扱い


クリップの長さは、記録タイムに開始前・終了後の追加時間を加えたものです。ファイル名のタイムは動画の長さではなく、記録タイムを表します。映像フレームなどの境界により、実際の長さには小さな差が出ることがあります。


タイムを取得できない終了時は、元動画を先に保存し、入力できるようにします。保存された元動画は後から確認できます。ただし、通信やOBS側の状態によっては保存できない場合もあります。OCRによるタイム読み取りは実装されていません。


「最新動画だけ残す」は1周と3周で個別に設定できます。タイム未確定の元動画は、この整理によって削除されません。念のため、大切な動画は別の場所にもバックアップしてください。


## 命名ルールとX投稿


ファイル名・フォルダ名には、`{course}`、`{aircraft}`、`{kind}`、`{record}`、`{year}`、`{month}`、`{date}`、`{time}`、`{datetime}`、`{full_date}`を使用できます。`{kind}`は`1lap`または`3lap`です。


例：`{course}_{kind}_{record}s_{datetime}`


Windowsで使えない文字や予約名を指定した場合は、修正を求める画面が表示されます。Xの投稿文も差し込み項目を使って編集できます。


## 更新とデータ


「録画設定」→「更新を確認」から、[このリポジトリのReleases](https://github.com/Ak1rA-PRG/FPVSIM-Clipper/releases)を確認します。


設定・記録はアプリフォルダ内の`fpvsim_clipper_data.json`と`fpvsim_clipper_internal`に保存します。新しいフォルダに移す際は、アプリを終了してからこれらもコピーしてください。


アプリは受信したWebSocketメッセージを`fpvsim_clipper_ws_debug.log`に記録します。ログや設定ファイルには接続情報や参加者の情報が含まれる可能性があります。
