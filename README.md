# FPVSIM-Clipper

VelociDroneの自己ベスト更新を検出し、OBS Studioのリプレイバッファから飛行動画を保存する非公式ツールです。

FPVSIM-ClipperはBat Cave GamesまたはOBS Projectが開発・公認・支援するものではなく、両者との提携を意味しません。

## 主な機能

- 1周・3周の自己ベストを検出し、記録タイムに合わせてクリップを保存
- クリップの開始前・終了後の余裕時間をそれぞれ設定（初期値は開始3秒前、終了1.5秒後）
- コース名・機体名の自動取得と手入力
- ファイル名・保存フォルダの命名ルールをカスタマイズ
- 保存した結果を選び、Xへの投稿文を作成
- タイムを取得できなかった場合は、元動画を先に確保してからタイムの入力を案内
- 動画や画像をクリップの前後に挿入、フェードを設定

タイム未取得の元動画は、入力をキャンセルしても残ります。取得・保存・切り出しに失敗した場合はアプリの表示を確認してください。Xへの投稿時、動画は手動で添付します。

## 対応環境

- Windows 10 / 11（64ビット）：配布版はPythonのインストール不要
- OBS Studio：録画・リプレイバッファに必要
- VelociDrone：接続にはゲーム側でWebSocket通信を有効にする必要があります

Windows版はFFmpegを同梱せず、OSのメディア機能で切り出します。メディア機能が不足しているWindows N版や、対応していないコーデックの動画では処理できないことがあります。再エンコードなどの処理中はPCへの負荷が増える場合があります。

macOS向けの処理はソースにありますが、Mac実機での検証や配布用アプリの作成はまだ行っていません。

## インストール

1. [Releases](https://github.com/Ak1rA-PRG/FPVSIM-Clipper/releases)からWindows版ZIPをダウンロードします。
2. ZIPを任意の新しいフォルダに展開します。
3. OBS StudioとVelociDroneをインストールして起動します。
4. `FPVSIM-Clipper.exe`を起動し、初期セットアップウィザードに従います。

Releasesにまだファイルが公開されていない場合は、ダウンロードできません。アプリ内の更新確認も、正式なリリースが公開されるまで使用できません。

## 初期設定

### OBS Studio

1. 映像と音声のソースを設定し、プレビューで確認します。
2. 「ツール」→「WebSocketサーバー設定」でWebSocketサーバーを有効にします。
3. 「設定」→「出力」でリプレイバッファを有効にします。最大時間は、最長のレース時間に前後の追加時間を加え、さらに余裕を持たせてください。
4. ウィザードにOBSの接続先・ポート・パスワードを入力します。

録画形式はMP4またはMOV、映像はH.264、音声はAACを推奨します。保存先の基準はOBSの録画設定です。

### VelociDroneとアプリ

1. VelociDroneの設定で「Websocket Communication」を有効にします。
2. ウィザードで接続設定を確認し、保存対象やファイル・フォルダの命名ルールを設定します。
3. 「記録」タブで1周、3周、または両方を選び、「監視開始」を押します。
4. OBSとVelociDroneに接続し、リプレイバッファが開始されると録画状態になります。

ウィザードは「録画設定」タブから再実行できます。コース名・機体名を自動取得できないときは、手入力してください。

## 保存とタイムの扱い

クリップの長さは、記録タイムに開始前・終了後の追加時間を加えたものです。ファイル名のタイムは動画の長さではなく、記録タイムを表します。例えば、記録が105.034秒で追加時間の合計が4.5秒なら、動画の長さは約109.534秒です。映像フレームなどの境界により、実際の長さには小さな差が出ることがあります。

タイムを取得できない終了時は、元動画を先に保存し、入力できるようにします。保存された元動画は後から確認できます。ただし、通信やOBS側の状態によっては保存できない場合もあります。OCRによるタイム読み取りは実装されていません。

「最新動画だけ残す」は1周と3周で個別に設定できます。タイム未確定の元動画は、この整理によって削除されません。念のため、大切な動画は別の場所にもバックアップしてください。

## 命名ルールとX投稿

ファイル名・フォルダ名には、`{course}`、`{aircraft}`、`{kind}`、`{record}`、`{year}`、`{month}`、`{date}`、`{time}`、`{datetime}`、`{full_date}`を使用できます。`{kind}`は`1lap`または`3lap`です。

例：`{course}_{kind}_{record}s_{datetime}`

Windowsで使えない文字や予約名を指定した場合は、修正を求める画面が表示されます。Xの投稿文も差し込み項目を使って編集できます。

## 更新とデータ

「録画設定」→「更新を確認」から、[このリポジトリのReleases](https://github.com/Ak1rA-PRG/FPVSIM-Clipper/releases)を確認します。Windows版の自動更新には、正式リリースに`FPVSIM-Clipper-Windows.exe`が必要です。実際のGitHubリリースを使った更新は未検証です。

設定・記録はアプリフォルダ内の`fpvsim_clipper_data.json`と`fpvsim_clipper_internal`に保存します。新しいフォルダに移す際は、アプリを終了してからこれらもコピーしてください。以前の名称の版からは自動移行されないため、旧データは削除せず保管してください。

アプリは受信したWebSocketメッセージを`fpvsim_clipper_ws_debug.log`に記録します。ログや設定ファイルには接続情報や参加者の情報が含まれる可能性があります。公開・共有する前に内容を確認し、機密情報を取り除いてください。

## ソースから実行

Python 3.12を用意し、プロジェクトのフォルダで以下を実行します。

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python fpvsim_clipper_qt.py
```

上記はWindows向けです。`py`が見つからない場合はPythonをインストールするか、その環境で使えるPython 3.12の起動コマンドに置き換えてください。ソース実行にもOBS StudioとVelociDroneが必要です。
