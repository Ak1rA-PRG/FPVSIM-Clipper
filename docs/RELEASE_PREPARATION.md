# v1.0.0 公開準備の状況

このディレクトリは配布候補のソースであり、正式リリースではありません。実際の配布物の検証と権利関係の確認が必要です。設定ファイル、実際の記録、デバッグログは含めていません。

## 実施済み

- アプリのウィンドウ表示と更新判定を 1.0.0 に変更。
- 更新のバージョン比較についてテストを追加。
- GNU公式の LGPL 3.0 と GPL 3.0 の本文を LICENSES に追加し、PySide6 / Shiboken 6.10.3 の公式ソースへの参照を記載。
- Windows で Qt / PySide6 の DLL と Python コードが外に見えるフォルダ形式の試験ビルドを作成。Qt 6.10.2 に差し替えた状態で動画切り出しが完了することを確認。これはライセンス適合の証明ではありません。
- Qt 6.10.3 の該当ソース４種を取得し、Qtの著作権表示94件から参照されるライセンスファイルの存在を検査。
- Python Software Foundation署名の Windows 版 Python 3.14.10 を使用。Qtの不要なOpenSSLプラグインを除き、無関係な開発ツール由来のDLLが混入しないビルド設定を追加。
- 配布者から Visual Studio Community の個人利用である旨の回答を取得。Visual Studioの再配布用CRTを使用するビルド設定と、Microsoft Distributable Code の別途適用される条件を示す資料を追加。
- フォルダ形式では旧来の単一 EXE 置換機能を使わず、更新時に GitHub の配布ページを開くように変更。更新の確認自体は利用可能です。

## 公開前の必須確認

- `THIRD_PARTY_NOTICES.md` の依存物一覧と、実際の最終配布物を照合する。追加のMesa / LLVMを含むQtの任意ソフトウェアOpenGL描画器は配布候補から除外しているため、OpenGL用ソフトウェア描画へのフォールバックが必要な環境での動作は保証されない。
- 取得済みのQt / PySide6ソースと実際の公式ホイールの対応、ビルド時の改変や追加部品の有無、利用者が入手可能な提供先の継続性を確認する。配布物とともに対応ソースを用意することを推奨する。
- Microsoftの再配布条件では、下流の配布者や利用者に適切な条件への同意を求める必要がある。`MICROSOFT_REDISTRIBUTABLE_NOTICE.md` を用意したが、同意の取得方法と条件の十分性は配布者が確認する。
- Windows の OBS と VelociDrone で実際に飛行し、1周・3周の保存、前後の時間、タイム欠落時の元動画保存、再接続を確認する。録画と映像の書き出しを別途検証する。
- 動画を含まない新規の利用者データで配布物を作り、Python 未導入環境で起動・初期設定・保存を確認する。
- サンドボックス内の Windows 非同期処理は停止するが、通常の Windows 環境では動作した。通常環境で既存の動画切り出し試験を実行し、出力が作られ元動画が残ることを確認した。OBS と VelociDrone での実飛行テストは別途必要。
- VelociDrone の連携方法、特にローカルデータベースの直接読み取りに関する公式条件を確認する。
- ソースと配布物の内容、過去のコミット履歴に不要な個人情報がないか確認し、GitHub リポジトリの公開と正式リリースを行う。
- 既存テスト版のバージョンは 32.0.3 のため、更新機能は 1.0.0 を新しいバージョンとみなさない。テスト版からの移行方法を案内する。
